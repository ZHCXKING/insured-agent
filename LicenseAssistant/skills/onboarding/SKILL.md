# 上牌申请入职引导技能

## 概述
本技能用于在收到顾问上牌申请后，依次执行：存档记忆 → 发送欢迎语 → 询问上牌经历 → 收集上牌资料 → 推送表格。

## 流程

### 第一步：识别上牌申请
当收到类似以下格式的消息时，判定为上牌申请：
- 包含"上牌申请"关键词
- 包含姓名、学历、工作经历、推荐人等结构化信息

识别后，将申请信息存档到长期记忆（/memories/）中，键名为"上牌申请"。

### 第二步：发送欢迎语
请读取同目录下的 `onboarding_templates.md` 文件，使用 `send_message` 工具依次发送以下消息（每条消息单独调用一次 send_message）：
1. **欢迎语-1**：AWM欢迎词
2. **欢迎语-2**：自我介绍（上牌小助手Lili）
3. **主动询问-1**：询问是否之前上过牌

### 第三步：根据回答分支

#### 分支A：之前上过牌
- 回复："好的，既然您之前已经上过牌，后续流程我们会简化处理，请留意群内通知即可。"
- 跳过资料收集步骤

#### 分支B：之前没上过牌
继续第四步收集资料。

### 第四步：收集上牌资料
使用 `send_message` 工具按顺序发送以下内容（每条消息单独调用一次 send_message）：
1. **资料-1**：上牌所需资料清单
2. **资料-2**：资料提交邮箱及邮件主题格式
3. **资料-3**：温馨提示

### 第五步：推送A1表格和签署指引
使用 `send_wedrive_file` 工具推送文件：
- file_names: ["A1表格", "A1表格签署指引"]
- 提醒顾问：A1表格中地址、手机号必须为香港

## 注意事项
- 欢迎语和资料话术必须严格按照模板内容发送，不要自行改写
- 存档记忆时，提取申请中的关键信息（姓名、学历、推荐人、直属上级、拟任职级、牌照号等）
- 如果顾问的回答不明确（既没说上过也没说没上过），主动追问确认
