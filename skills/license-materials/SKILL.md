# 上牌资料准备技能 (License Materials Skill)

## 概述
此技能用于提供 IA 牌照注册所需的资料清单、邮件提交指南以及 A1 表格的相关链接。

## 本地参考资源 (Local Assets)
本技能文件夹下包含以下两个本地 PDF 文档供你作为知识库参考。如果顾问向你提问关于“A1表格具体如何填写”、“某一项应该填什么”等细节问题，**请务必先使用你的内置 `read_file` 工具读取以下文件内容**，然后再给出准确解答：
- 读取路径 1：`/skills/license-materials/（AWM）A1.pdf` （A1 申请表原件）
- 读取路径 2：`/skills/license-materials/（AWM）簽署指引-A1.pdf` （A1 签署官方详细指引）

## 执行指令
当顾问需要上牌清单资料时，请将以下信息准确无误地发送给用户：

**上牌所需资料清单：**
1. **香港身份证 (HKID)**
2. **香港住址证明 (HK Address Proof)**
3. **银行账户证明**（如月结单）
4. **毕业证书**
5. **学位证书**
6. **内地院校毕业：** 需额外提供【学信网】学历认证报告
7. **IIQE 成绩单：** (Paper 1, 2, 3, 5)，视申请牌照类型而定
8. **CPD 记录：** 对上一年记录（如有请提供）
9. **非永居身份：** 需提供护照
10. **非永居身份：** 需提供有效 Visa
11. **学生签证：** 需另外提供 NOL（入境处出具的学生签证批准函）

**重要提醒：**
- A1 表格中的**地址、手机号**必须填写香港本地信息。
- 以上资料准备齐全后，请发送至官方邮箱：`license.tr@awm.com.hk`
- **邮件主题格式：** `Request for IA license registration-(您的英文名字)`

以上是上牌所需准备的资料，您可以提前开始准备。准备完成后，按照上述要求发送至指定邮箱即可。
